## Residual limitations

- Starter data is not pretrained weights and does not establish fluent open-domain conversation or factual expertise.
- Byte tokenizer uses more context for Cyrillic than a trained subword tokenizer. FP32 dense attention remains; no mixed precision/FlashAttention claimed.
- The 128 checkpoint guard remains; cleanup is explicit, not silent automatic deletion. The kept chain includes the active revision.
- Chat and replay are plaintext. Discarding pending work is not erasure, forgetting or unlearning. The replay journal retains tombstones.
- Cancellation interrupts between native operations, not inside an arbitrary GPU kernel. Native load and model parsing have bounded-input but not hard real-time cancellation.
- Corpus checks detect exact/normalized overlap, not all semantic leakage. Validation is repeatedly consulted, not a blind score.
- The current validation of an existing workspace is preserved across corpus upgrades; its scores are not comparable to a new model on a newer validation set without a separate evaluation.
- Revision high-water prevents future reuse after this version is installed; it cannot discover already-deleted historical IDs from older versions.
- File flush/rename is not a certification of power-loss durability on every filesystem. Files have hashes, not signatures.
- No pretrained model download, original `.bin` importer, HTTP service, distributed training or device VRAM telemetry is claimed.
