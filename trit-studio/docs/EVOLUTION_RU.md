# Наблюдаем эволюцию одной модели

Это три разных состояния, а не готовый маленький интеллект, спрятанный внутри конструктора.

## 0. Случайные веса

Во второй вкладке оставьте «После создания: 0 · Без обучения» и нажмите «Создать без обучения».
Архитектура и веса будут созданы, но шагов оптимизатора будет ровно0. Чат станет доступен, автообучение останется выключенным.
Счётчик шагов0 означает отсутствие обучения. Прикреплённый для будущего этапа базовый материал не означает, что веса уже его изучили.
Нельзя ждать осмысленной речи от случайной сети. Размер сети не увеличивается при обычном дообучении.

## 1. Базовый претрейн

Поговорите с нулевой моделью, затем во второй вкладке выберите «Базовый претрейн: только короткие тексты».
Нажмите «Запустить базовый претрейн». Для первого эксперимента интерфейс предлагает200 шагов после нулевого создания; число можно изменить.
Используется только отдельный pretrain.jsonl:48 простых текстов. Разговорный корпус, свои выбранные файлы и онлайн-исправления сюда не добавляются.
Это обучение с нуля на маленьком корпусе, не скачивание чужой модели и не гарантия даже хорошего русского языка.

## 2. Разговорное обучение

После базового этапа выберите «Разговорный корпус + выбранные файлы». Флажок обновления встроенного корпуса должен быть включён.
Нажмите «Дообучить текущую модель». Эта же архитектура и её текущие мастер-веса продолжат обучение, без создания другой случайной сети.
Ранее прикреплённые базовые тексты сохраняются для повторения. Свои файлы можно добавить здесь или выбрать отдельный режим своих данных.
После завершения автообучение остаётся выключенным. Когда сравнение закончено, включите его явно в чате для обучения во время разговора.

## Чистое сравнение

Задавайте одинаковые вопросы, каждый раз начиная новый чат. Для воспроизводимости выставьте температуру0 и одинаковый лимит ответа.
Не включайте автообучение между контрольными запросами и не подтверждайте эти ответы как учебные примеры.
Сравнивайте видимый ответ, ревизию, шаг и число изменённых значений. Число параметров остаётся прежним.
Лучше записать несколько собственных проверочных вопросов заранее и НЕ добавлять их в датасет.
Отдельные вопросы модели и результаты проверки сами по себе не доказывают способность свободно разговаривать.

## Эталоны, которые не исчезнут при очистке снимков

В рабочей папке появляется каталог evolution:
- 00-untrained/model.tritmodel: первые случайные веса.
- 01-basic/model.tritmodel: результат первого успешно завершённого базового этапа.
- 02-conversation/model.tritmodel: результат первого успешно завершённого разговорного этапа.
- 03-custom/model.tritmodel: первый завершённый отдельный этап своих данных, если запускался.

Кнопка «Открыть папку эталонов этапов» показывает этот каталог. Через верхнюю кнопку «Файл…» можно выбрать нужный model.tritmodel.
Это режим только CPU-инференса. Для продолжения обучения снова откройте исходную рабочую папку модели, не файл эталона.
stage.json рядом содержит ревизию, шаг и контрольную сумму. Эталон первого прохождения не заменяется при следующих дообучениях.
Если сохранение копии не удалось, интерфейс показывает предупреждение; уже опубликованные мастер-веса не откатываются из-за этой копии.
Эталоны не содержат оптимизатора. Для точного возобновления обучения нужен полный рабочий снимок.

## Быстрый путь тоже остался

«После создания: 2 · Сразу обучить разговорному корпусу» сохраняет прежний сценарий одним действием.
Он не подходит для наблюдения отдельного базового этапа: разговорный корпус будет выбран сразу.

## Уточнения v8

Базовые 48 текстов оставлены побайтово теми же, что в v7. Растёт разговорный корпус, а не незаметно меняется нулевая точка эксперимента.
В разговорном этапе теперь 1674 учебных примера плюс ранее прикреплённые базовые тексты. Первое разговорное обучение требует включённого
добавления встроенного корпуса. Нельзя выключить данные, обучить только базу и назвать получившийся эталон разговорным.
Для первого собственного этапа выберите хотя бы один файл. Базовый этап с выбранными собственными файлами выдаст понятное объяснение:
очистите список либо выберите другой этап. Ничего не игнорируется молча.

Повторный запуск не обновляет первый эталон: сообщение покажет, что сохранена исходная ревизия и её шаг, а новые веса находятся в рабочей папке.
Старые рабочие папки без подтверждённого происхождения материала открываются, но для первого продолжения разговорного/собственного этапа
могут потребовать явно подключить соответствующие данные. Подпись старого этапа не является доказательством того, на чём обучались веса.
Если поменять длину последовательности обучения, прежний минимум контрольной ошибки не переносится как сопоставимый рекорд.
Проверка текущих весов до и после обучения сохраняется; сам контрольный набор существующей модели не заменяется.

## Аудит v9

Базовый pretrain.jsonl (48 текстов) и все прежние проверочные файлы сохранены без изменения байтов. Добавлен материал только для дальнейшего разговорного обучения и отдельного контроля. При сохранении ускорено повторное использование неизменных JSON-данных, но веса не обучаются «в фоне» из-за самого сохранения или открытия. При повреждении/несовпадении счётчиков снимок не должен выдаваться за корректный предыдущий этап.
