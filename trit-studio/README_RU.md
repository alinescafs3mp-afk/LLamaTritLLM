# Trit Studio · аудит16

Готовый исходный кумулятив для Грока. Скомпилированный результат после реальных проверок: `TritStudio-win-x64-update.zip`.
Это небольшое обновление поверх совместимой установленной папки v14/v15, без повторной упаковки CUDA/LibTorch/Avalonia/.NET.
См. docs/UPDATE_RU.md. Предыдущие исходные кумулятивы для применения этого полного комплекта не требуются.

Выбор в шапке является единой активной моделью для двух вкладок. Архитектура выбранной модели только для чтения; создание другой
сети вынесено отдельно. Масштаб50/65/80/100/125%, компактная компоновка, сворачиваемые параметры и оценка ответов. Новая кнопка
«Очистить чат» начинает разговор с пустым контекстом после подтверждения, но сохраняет черновик, веса, журнал и очередь обучения.

«Модели…»: локальные рабочие папки перемещаются в корзину приложения, внешние файлы только убираются из списка. Файлы сохранены
в model-trash с restore.json, место не освобождается. Модель другого окна/тренера защищена блокировками. Не выполняется удаление
корневых каталогов и путей со ссылками. «Сохранить диагностику» помогает разбирать качество обучения без включения текста чата.

Для эволюции:0 шагов/случайные веса, затем отдельный базовый набор48 текстов и разговорный корпус. Быстрое создание сразу с
разговорным обучением также поддерживается. Обычное обучение меняет значения весов, не количество параметров. Никакие скрытые
предобученные знания не загружаются. Не считайте плохой ответ доказательством собственной ошибки настройки.

Корпус3418 записей:2730 учебных,368 контрольных,272 отложенных,48 базовых. Старые отложенные наборы и базовый набор неизменны.
Токенизатор по-прежнему байтовый,262 ID; модельный формат Trit Studio V1 сохранён. Это не готовые веса и не гарантия связной речи.

В среде автора выполнены проверки данных/структуры/независимые численные спецификации/применение пакета. C# и новый интерфейс,
Windows/CUDA здесь не запускались: их проверяет Грок и ноутбук. Отчёты docs/AUDIT_V16.md и reports/*.json различают эти границы.
