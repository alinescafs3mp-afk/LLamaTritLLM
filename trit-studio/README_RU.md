# Trit Studio v22

Этот выпуск развивает перенос на другие формулировки, а не добавляет подстановки ответов в чат.
В курсе появилась отдельная выборка настоящих конечных ответов на вопросы о фактах. Промежуточные «Понял»
остаются учебными примерами, но больше не размножаются в этой приоритетной части пакета.

«Подготовить разговорный курс» включает v22 явно:6000шагов, пакет16, длина до512, пикLR0,001 с разогревом
и снижением, равный вес примеров и автоинтервал сохранения. Обучение запускается отдельной кнопкой.
Флажок v22 сохраняется для выбранной модели. В старых сохранённых планах он выключен.

«Проверить разговор» сохраняет старые проверки и дополнительный отчёт на62заданиях. История состоит из
реальных ответов модели. Точное совпадение с эталоном не является процентом качества речи: читайте текст.
Новые учебные данные и фазы нельзя считать доказательством, что произвольная беседа уже получилась.
Реальные результаты независимых экспериментов: docs/LEARNING_RESULTS_V22_RU.md.

В комплекте5955исходных записей, включая408контрольных,402проверочных и48старых базовых. Все старые файлы
данных сохранены. Новые160коротких примеров и1278шаблонных контекстных упражнений подключаются только
через явный курсv22. Словарь262ID и формат весовV1 прежние. Новая случайная модель не получает чужих знаний.

Доставка: небольшой TritStudio-win-x64-update.zip поверх совместимой установки, без повторных библиотек.
Модели выбираются общей шапкой для обеих вкладок. Enter отправляет, Shift+Enter переносит строку.
Очистка чата отделяет новый контекст, не удаляет веса/журнал/очередь. Инструкции: GROK_START_HERE.md.
