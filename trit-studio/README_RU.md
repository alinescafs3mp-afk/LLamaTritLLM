# Trit Studio · аудит17

C# настольная лаборатория собственных маленьких моделей. Avalonia, TorchSharp для обучения, отдельный CPU-инференс.
Три блока: текущая модель, создание другой модели, дообучение выбранной. В шапке один активный объект для обеих вкладок.
Создание и дообучение имеют раздельные настройки. Нулевая модель имеет строго0 шагов; базовый этап и разговорное обучение отдельные.

Основное изменение17: проверяем не только снижение ошибки, но и способность нативной сети выучить6 реплик с генерацией
через записанный файл. Добавлена диагностика выбранной модели и предупреждение про LR<1e-5. Память нулевого создания
больше не считается по пакету будущего обучения. Подробности docs/TRAINING_DIAGNOSIS_RU.md и docs/AUDIT_V17.md.

Поставляется небольшой update ZIP без повторных библиотек. См. docs/UPDATE_RU.md. Пользовательские веса не входят в него.
Один явно маркированный тестовый файл checks/learning-reference.tritmodel содержит6 обученных реплик, не универсальный мозг.
Он никогда не подключается автоматически и не используется как предобучение пользовательских моделей.

Данные:2762 учебных,376 контрольных,280 отложенных,48 отдельных базовых =3466. Готового универсального собеседника нет.
Веса модели не растут в количестве от обычного обучения; меняются значения.

Исходный автор проверил Python-математику/данные/упаковку. C#/Windows/GUI/CUDA он здесь НЕ запускал. Их проверяет Грок
перед выдачей сборки и ноутбук после объединения обновления с установленной папкой. Скрипты не заменяют драйверы.
