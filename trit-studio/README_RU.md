# Трит: кумулятив аудита v14

Настольная лаборатория на C#: чат, создание своей небольшой модели и дообучение её весов.
Это исходники для Грока, не скомпилированная программа и не готовые обученные веса.
В авторской среде нет .NET SDK. C#-сборка, 314 определённых управляемых проверок,
настоящее окно Avalonia, TorchSharp и CUDA здесь НЕ ЗАПУСКАЛИСЬ.

## Как наблюдать изменения модели

По умолчанию создаётся случайная модель с нулём шагов и выключенным автообучением.
Отдельно запускается базовое обучение на 48 неизменных текстах, затем разговорное обучение
на 2474 учебных примерах. Вручную проведённые этапы оставляют автообучение выключенным.
Для сравнения задавайте одинаковые вопросы в новом чате с температурой 0 и одинаковым лимитом ответа.
Веса меняются, число параметров остаётся прежним. Первые эталоны этапов находятся в evolution;
это файлы только для чата. Для продолжения обучения нужен исходный полный рабочий каталог.
Быстрый режим создания с разговорным обучением тоже сохранён как явный отдельный выбор.

## Сохранённые улучшения v13

CPU-attention обрабатывает каналы значений через переносимые векторные операции, с обычным
скалярным путём там, где он нужен. Новых зависимостей для инференса нет; выигрыш измеряется на целевой машине.
История читается до однажды зафиксированной границы файла, а не до меняющегося конца.
Разбираются самые новые записи, пока не собрано достаточно корректных обменов. Старый файл не переписывается.
После ошибки или отмены запрос «не обучать» возвращается с прежним исключением; уже набранный новый черновик не заменяется.

Весь корпус: 3090 записей, включая 328 контрольных, 240 отложенных и 48 отдельных базовых.
Базовые тексты и все двенадцать прежних отложенных файлов сохранены побайтово.
Максимальная полная последовательность: 453 байт-токенов, стандартная длина обучения: 512.
Ни размер корпуса, ни количество написанных тестов не доказывают качество обученной модели.
Исключение из обучения не удаляет локальную переписку и не отменяет ранее изменённые веса.

## Что передать Гроку

Отдайте внешнюю папку tritstudio-audit14 целиком. Начало: 00_GROK_START_HERE.md.
После применения и всех проверок Грок должен выдать абсолютный путь к свежему
artifacts/TritStudio-win-x64-portable.zip, его SHA256, коммит вашего форка и реальные результаты проверок.
Весь скомпилированный ZIP переносится на ноутбук. После распаковки: Check-laptop.cmd, затем Start-TritStudio.cmd.
Старые пользовательские рабочие папки не нужно копировать внутрь новой папки программы.
Подробности: docs/AUDIT_V14.md, docs/PERFORMANCE_V14.md, docs/LAPTOP_ACCEPTANCE_RU.md.

## Главное в v14

Новая рабочая папка проверяется до закрытия текущего тренера и очистки чата. Ошибка её метаданных или модели не должна
уничтожить текущую сессию. Проверенные веса и историю не читаем повторно при переключении. Временная память под старую
и новую модели при этом сосуществует: это компромисс ради безопасной проверки, не обещание меньшего пика RAM.
Первый нулевой снимок использует исходные веса без обратной копии с устройства; после обучения/восстановления это запрещено.
RMSNorm и остаточное сложение используют переносимые векторы с обычным резервным путём. Реальные замеры остаются Гроку.
