TRIT STUDIO · v18 · UPDATE ПО УМОЛЧАНИЮ

Это не новая установка. Закройте приложение, сохраните копию существующей установленной папки, затем скопируйте СОДЕРЖИМОЕ
папки TritStudio-win-x64-update поверх старой v14/v15, заменяя файлы и ОБЪЕДИНЯЯ каталоги. Не удаляйте старые библиотеки.
НЕ заменяйте всю папку trainer-cuda и не применяйте зеркалирование с удалением. Модели в AppData обновление не затрагивает.

Check-Update.cmd: проверить новые файлы и оставленные библиотеки без скачивания.
Check-laptop.cmd: реальные тесты и CPU/CUDA-бенчмарки; отчёт diagnostics/.../RESULT.json.
Start-TritStudio.cmd: открыть приложение. При несовпадении библиотек передайте Гроку ошибку, не удаляйте DLL наугад.
SDK на ноутбук для запуска не нужен при совместимой предыдущей установке. Драйвер NVIDIA автоматически не меняется.

Выбранная в шапке модель является общей для чата и обучения. «Файл…» открывает модель только для чата; для дообучения нужна
рабочая папка с мастер-весами и оптимизатором. Вкладка обучения отдельно показывает текущую архитектуру только для чтения и
свёрнутый блок создания ДРУГОЙ модели. Новая модель автоматически выбирается после создания.

Масштаб50/65/80/100/125% задаётся в шапке, по умолчанию80% с компактными отступами. «Параметры ответа» раскрывают боковую панель.
Ошибки и результат действий видны внизу, крупной пустой панели нет. Обучающие кнопки ответа раскрываются по запросу.
«Модели…» позволяет удалить любую локальную запись. Управляемая папка перемещается в model-trash после подтверждения имени;
внешний файл только убирается из списка. Корзина сохраняет веса и переписку, место не освобождается.

«Очистить чат» возле сообщения начинает новый разговор без прежнего контекста после подтверждения. Набранный черновик и его
флажок исключения сохраняются. Журнал на диске, очередь обучения, режим автообучения и уже изменённые веса НЕ удаляются.
Не используйте очистку чата как обещание забывания: уже ожидающие примеры могут обрабатываться отдельным тренером.

Для наблюдения эволюции создайте «0 · Без обучения»: ноль шагов, случайные веса. Затем отдельно базовый претрейн48 текстов и
разговорное обучение. Прямое «2 · Сразу обучить разговорному корпусу» также поддерживается. Эталоны первых этапов в evolution
предназначены только для сравнения/чата; продолжение обучения использует рабочую папку. Автообучение включается явно.

Корпус conversation-ru-v18:2826 учебных,388 контрольных,292 отложенных и48 отдельных базовых =3554. Готовых предобученных весов
нет. Слабая связность не обязательно означает неправильную настройку: проверьте реальные шаги/ошибки и «Сохранить диагностику».
r12 является ревизией, не числом шагов. Корпус не гарантирует свободной беседы. Подробности в docs/QUALITY_DIAGNOSTICS_RU.md.

Текст чата/очереди хранится локально в открытом виде. Исключение из обучения не удаляет журнал и не отменяет прежние обновления.

V16: Enter отправляет один раз, Shift+Enter оставляет перенос. Проверьте это на реальном окне.
Если active.json потерян, но ревизии остались, открытие остановится без отключения прежней модели. Не создавайте новую поверх повреждённой папки.

V17: три отдельных блока настроек; независимое создание без оценки активаций будущего обучения.
Проверка обучения и независимый шестирепличный тестовый файл: docs/TRAINING_DIAGNOSIS_RU.md.
В checks/learning-reference.tritmodel есть только специальная модель для проверки шести выученных реплик; она не включена в создание ваших сетей.

V18: подсказки параметров через2сек; свои настройки сохраняются автоматически, «Заполнить учебным профилем» не является кнопкой сохранения.
Учебная и контрольная точность байт-токенов видны в шапке. Это не процент интеллекта и не оценка качества речи.
